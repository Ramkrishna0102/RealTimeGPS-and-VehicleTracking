# 🚗 RealTimeGPS-and-VehicleTracking - EasyTrack

## 📌 What is the Project?

**EasyTrack** is a real-time GPS and vehicle tracking system that helps manage and monitor vehicles, drivers, fuel usage, geofencing, and reminders. It’s built using **React**, **Node.js**, **MongoDB**, and **Google Maps API**.

---

## 🌟 Features

- 📍 Live vehicle tracking on map  
- 👨‍✈️ Driver and user management  
- ⛽ Fuel usage monitor  
- 🛑 Geofence alerts  
- 🔐 Login & Signup  
- 🛠 Reminders for vehicle maintenance  
- 📊 Dashboard view  

---

## 🔁 Flowchart (Simple Flow Description)

```
Login/Signup → Dashboard → Select Vehicle → Track Location on Map  
                      ↘ Manage Drivers/Vehicles  
                      ↘ Monitor Fuel & Set Reminders  
                      ↘ Geofencing Alerts  
```

## 🛠 How to Run Locally

### 1. Clone Repo
```bash
git clone https://github.com/Ramkrishna0102/RealTimeGPS-and-VehicleTracking.git
```

### 2. Setup Backend
```bash
cd Backend
npm install
```
Create `.env` file:
```
MONGO_URI=your_mongo_db_uri
GOOGLE_API_KEY=your_google_maps_api_key
PORT=5000
```
Start server:
```bash
node index.js
```

### 3. Setup Frontend
```bash
cd ../EasyTrack
npm install
npm run dev
```

### ✅ Frontend: http://localhost:5173  
### ✅ Backend: http://localhost:5000
